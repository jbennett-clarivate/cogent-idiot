This emblem is rendered with WebGL, which this browser is not allowing.

LibreWolf, Tor Browser and hardened Firefox profiles restrict WebGL by default, because it can be used to fingerprint your machine. That is a deliberate privacy trade-off, not a fault in your setup.

In about:config, check these in order — the first is the usual cause, and it stays in effect even when the second is already false:

  • privacy.resistFingerprinting — set to false
  • webgl.disabled — set to false
  • webgl.force-enabled — set to true if your GPU or driver is blocklisted

Reload after changing one. about:support lists the WebGL rows and any blocklist reason under Graphics.
